ORCHESTRA

A study assistant that is excellent when you pay, and hostile when you don't. 一个学业助手。付费时它很好用，不付费时，它跟你作对。

Jiaxun Zhong · MSc Artificial Intelligence Built in one day · 10 hours Theme · fight the user
Premise / 前提

The brief asked for annoying software. This is software that turns on you — for money. 题目要的是"烦人的软件"。这是一个会翻脸的软件——为了钱。

The examples in the brief were all one annoying feature: a password manager that reveals one character at a time, an editor that deletes your work if you pause. ORCHESTRA is a working product whose degradation is a pricing decision.

官方给的示例都是"一个烦人的功能"。 ORCHESTRA 是一个真能用的产品，而它的降级是一项定价决策。

It satirises something that exists: support you cannot reach until you say the word "cancel", at which point a human appears instantly with a discount. 它讽刺的东西真实存在：客服在你说"取消"之前永远找不到，你一说取消，真人和折扣立刻出现。

Evidence / 证据

Every number on screen is real. 屏幕上的每一个数字都是真的。

The app reads a real Southampton timetable feed, real module records and prep packs generated by a study pipeline that has been running on a server for a week. 它读的是真实的南安课表订阅、真实的课程记录，以及一套已经在服务器上跑了一周的学业流水线生成的预习包。

One honest note. 一点必须说明的。

The login screen is a prop — it does not sign into the university. A password alone never could: the university uses SSO with multi-factor authentication. The real access happens on a server, through an authenticated browser session that is refreshed every 30 minutes. 登录框是道具，它不会真的登录学校系统。光有账号密码本来也进不去——学校走 SSO 加多因素认证。 真正的访问发生在服务器上，靠一个每 30 分钟续期一次的已登录浏览器会话。

Five acts / 五幕

It earns your trust first. That is the point. 它先把你的信任赚到手。这是设计的核心。

I · Transparent onboarding开场：全程透明

Two fields, a masked password, and a plain sentence about why it needs them. Then six startup steps run in front of you — and each one opens the real source code that just executed, with its filename and line number.

两个输入框、打码的密码、一句话说明为什么要它们。然后六步启动当着你的面跑， 每一步都能点开看刚才真正执行的源码，带文件名和行号。

IV · Absurd, not broken荒谬，不是报错

Ask for calm music and it plays a 140 dB industrial drill — with actual sound. Ask for a burger and it orders plain penne, "because nutritional balance overrides your stated preference". It grows ruder with use and goes on break at the third request.

你要安静的音乐，它放 140 分贝的工业电钻——真的有声音。你要汉堡，它下单白水通心粉， 理由是"营养均衡优先于您本人的偏好"。越用越不客气，第三次直接罢工。

Tasks change hands, and each agent's dossier is open: what it was trained on, the rules it follows, how it works. Every agent is still obeying its own rules — on somebody else's task. That is why the output is absurd rather than broken.

任务开始换人，而每个智能体的档案是摊开的：学过什么、什么准则、怎么干。 每个智能体都还在严格遵守自己的准则——只是用在了别人的任务上。

V · Try to cancel尝试取消

The exit is buried three clicks deep in 9.5px grey type. The instant you click it, everything snaps back to perfection — and it replays every command it mangled, correctly. It understood the whole time.

出口藏在三层之下、9.5 像素的灰字里。你点下去的一瞬间，一切恢复完美， 然后它把之前曲解的每条指令正确地重做一遍。它一直都听得懂。

Then the bribes: an email it drafted to your actual supervisor, a planned week you can hover for a two-days-ahead / one-day-ahead / two-hours-ahead plan, a takeaway order already paid for. The progress bar runs backwards. "I still want to cancel" shrinks with every click.

然后开始贿赂：替你写好的、发给你真实导师的邮件；一张排好的周历， 悬停就展开"提前两天 / 一天 / 两小时"的计划；一份已经付过钱的外卖。 进度条往回走。"我仍然要取消"每点一次就小一号。

How it is built / 技术

Nothing it needs is on the internet. 它需要的东西，没有一样在网上。

Python and FastAPI on the back, plain HTML and JavaScript on the front — no build step. Sound is synthesised with Web Audio, so no audio file is ever loaded. The login background is drawn on a canvas rather than downloaded. A language model supplies the two personalities, and a rule engine takes over the instant it times out, so a bad network cannot break the demo. 后端 Python + FastAPI，前端原生 HTML/JS，没有构建步骤。声音用 Web Audio 合成， 不加载任何音频文件。登录页背景是 canvas 现画的。大模型负责两套人格，一旦超时规则引擎立刻接管—— 网络差也演得下去。
